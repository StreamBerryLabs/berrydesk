# Risks

- Signing/entitlements lead time: start enrollment now.
- Camera quirks: maintain compatibility list and "report your camera" template.
- H.265 in browsers/apps: mitigate by decoded raw frames.
- App pickiness: document rejected-virtual-camera cases.
- Lawful use: only feeds user is allowed to use; no covert capture.
- GPL contamination: dynamically link FFmpeg; audit licenses.
